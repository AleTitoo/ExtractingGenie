# Platinum-189 v1.1.0

Adds a separate Offline / Lab Edition with the same PDF extraction, source review, animation, and native Excel export. Its updater endpoints are disabled; startup and periodic update checks are disabled; the desktop window blocks external network requests. Updates are installed manually.

The lab edition uses its own per-user installation, library, shortcuts, and uninstall registration. It does not run historical GENIE Report Studio migration or compatibility steps. Standard and offline editions can coexist; reports are imported separately. No detector or GENIE integration is added. The standard edition retains its existing updater.

An offline build does not imply institutional approval or a completed independent security audit. Lab administrators should review and approve installation on shared acquisition computers.
