# Platinum-189 v1.1.1

The Offline / Lab Edition desktop and Start menu shortcuts are now named **Platinum-189 Lab**. Its static icon changes only the single outermost electron to the same muted red used by the animation's jumping electron. All positions, sizes, rings, inner electrons, and nucleus remain unchanged. The standard icon and both editions' animations are unchanged.

The lab installer refreshes the shortcut icon and renames existing Offline shortcuts. Installation and library folders retain their offline identity so manual updates preserve saved reports and remain separate from the standard edition. Offline networking restrictions are unchanged.
